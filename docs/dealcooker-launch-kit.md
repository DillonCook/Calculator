# Focused launch kit

Status: drafts and distribution preparation. No invitations or social posts have been sent, no advertising has been purchased, and no growth results are claimed.

## Start with rental buyers and small landlords

Lead with the question they already have: how much cash does this property need, what is left after costs, and what changes if the assumptions are wrong? Investor-friendly agents can share a clear analysis with a buyer or partner. Keep advanced strategies available without making new users learn every strategy first.

The app remains free to start without an account. Its first screen offers a guided property flow and a clearly marked sample. The marketing site should describe the current product, use engine-generated examples and link to the correct application origin. Do not advertise automatic listing-data imports, verified market rents, guaranteed returns or a guaranteed profitable offer.

## Short product description

DealCooker helps you work through a property's numbers before you make an offer. Start with the purchase price, financing, income and costs. See the cash you need, where the monthly money goes, and how a more conservative scenario changes the result. The assumptions stay visible so you can check them.

Start free: https://www.dealcooker.app/

## Partner introduction draft (unsent)

For buyers comparing rental properties, DealCooker gives us a common set of assumptions to review. We can compare financing and costs, see the downside, and share the result instead of passing around an unexplained return percentage. It does not replace quotes, inspections or property-specific due diligence.

## Sequence

1. Finish exact-commit app and landing verification.
2. Recruit the volunteer pilot described in `dealcooker-user-validation.md`.
3. Fix recurring comprehension or navigation problems.
4. Share an anonymized, consented example with a small number of relevant partners. Do not use a client's address, finances or testimonial without permission.
5. Measure meaningful second-property usage and returns before expanding distribution.

Do not launch a broad paid campaign or add more strategies to compensate for an unproven first-use experience. The first pilot still requires real participants; that dependency cannot be completed with generated transcripts, automated browser runs or empty CSV rows.
